Boolean permutation and proof execution evidence
================================================

Reversible predicates enlarge the signed-XOR label dictionary. A predicate
that ignores its target makes a conditional target flip an involution.
An ordered word has the reversed word as its inverse. A signed-XOR word
fixing label zero has identity label action, while its diagonal phase can
remain nonconstant. Controlled operation preserves that phase relative to
the disabled branch. Label equality and operator equality are distinct.

Exact finite label and oracle witnesses
--------------------------------------

TargetFlipWord accepts one through five data bits. Every cube excludes its
target and uses a data-only mask. Its outer control occupies the next bit.
The three retained N=21 words implement multipliers 2, 4 and 16 on every
five-bit label, including identity padding at labels 21 through 31. The
Rust checks cover all 192 packed control/data inputs and all 51 required
gate deletions. BooleanPermutation separately proves generic involution,
word inverse, control and signed-phase composition laws. The generic proof
does not replace the quantum-owned exact gate-word certificate.

For the N=21 maps, inputs 8 and 16 have XOR 24. The padded output at 24 is
24, whereas the XOR of their multiplier outputs is 27, 10 or 6. All three
maps fix zero, so each violates the affine XOR law. The degree-one ANF
matrix is still invertible for multiplier 2; the functional inverse,
multiplier 11, has degree-one matrix rank four. Functional invertibility
therefore supplies neither affinity nor an invertible affine skeleton.

recover_degree_promised_anf accepts a complete low-weight value-query
transcript at 0 <= d <= n <= 8. Unique recovery assumes an external degree
bound d. A degree d+1 monomial aliases zero at every queried input, giving
a permanent falsifier for promotion from samples to an unverified degree
promise. The query count is a constructive upper bound for this value-oracle
protocol. The computational checks retain their finite execution scope.

The translated cubics x0*x1*x2 and x1*x2+x0*x1*x2 differ and are not
complements, but their squared Walsh spectra agree. Uniform-input Walsh
probabilities lose more information than full phase-oracle access.
OracleAccess::UncontrolledPhase retains its full-access equivalence up to
complementation; the collision concerns only the named measurement.

Exact coordinate and action boundaries
--------------------------------------

Average/detail coordinates are (a+b)/2 and (a-b)/2, component by component
between the two doubling halves. Reconstruction returns average+detail and
average-detail. Both channels retain the original scalar-coordinate count.
The exact Rust round trips include dimensions 4096 and 65536; the scalar
Rocq theorem proves the inverse identities over canonical rationals.

The pair (1,-1) and zero both have average zero. Multiplication by (0,1)
gives product averages one and zero. An average-only product law therefore
cannot reproduce even scalar Cayley-Dickson doubling. Preserving the detail
channel addresses the missing information; the coordinate change itself
provides neither dimensional compression nor a hardware realization.

For octonions, L_(e1*e2)e4=e7 while L_e1 L_e2 e4=-e7. For sedenions,
x=e1+e10 and y=e4-e15 satisfy x*y=0 and x*x=-2e0. Hence L_x squared
annihilates y while L_(x*x)y=-2y. Exact rational matrix checks refute both
multiplicative and Jordan-square interpretations of the left-action map.
The algebra product and matrix composition retain their separate meanings.

The common binary channel p -> a(1-p)+bp has slope b-a in [-1,1] when
a,b lie in [0,1], so it contracts mean separation. The rational and real
Rocq ports use four independently supplied radius bounds. A larger output
center gap than the input center gap plus all four radii excludes one
common appended channel. Statistical coverage, stationarity and the means
themselves remain premises supplied by a separate experiment.

Canonical replay and execution admission
----------------------------------------

The mutators operate on registry/canonical/control_plane.sqlite3 through
an explicitly selected repository root. Inventory synchronization uses
`gororoba-db theorem identity sync-inventory --spec <sync.toml>
--regen-toml false`. The command preserves stable identities, claim links,
explanatory metadata and append-only events, while registering every listed
source in both roots. Source registration has source_only execution state.

`gororoba-db theorem identity record-kernel-evidence --spec <receipt.toml>
--regen-toml false` checks the exact source/import closure and retained role
files before compiling the complete source closure in a private scratch tree.
Fixed relative arguments and the pinned Rocq installation must reproduce the
retained target object digest. An independent kernel check and fresh labeled
assumption queries then verify every recognized declaration. The process
appends a version 2 event with internally-produced command outputs before
promoting the named theorem. Supplied command descriptions never execute.
A changed source, project or retained role file invalidates active admission.
Version 1 operator-declared receipts and raw artifacts remain immutable
history; a fresh distinct evidence key records trusted replay for activation.
The boundary trusts the host-selected compiler, libraries and store writer.
Kernel replay supplies source/object conformance rather than cryptographic
process attestation or physical/QPU evidence.

The integration exports compatibility views with
`provenance export-control-plane`, then refreshes registry signatures with
`make registry-integrity`. A destructive `gororoba-db build` import would
lose the append-only history and is excluded from the replay procedure.
